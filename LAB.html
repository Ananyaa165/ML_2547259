The prediction values obtained from Scikit Learn Linear Regression and Manual OLS Regression are almost similar.

Both graphs follow the same trend because Scikit Learn Linear Regression internally uses the Ordinary Least Squares approach.

Minor differences occur because Scikit Learn was trained using training data while manual OLS calculation was performed on the complete dataset.
